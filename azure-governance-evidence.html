Evidence Pack (Azure Cloud Governance)

This page consolidates screenshots showing how the Helios Azure Governance Platform was built, what risks were detected, what controls were implemented, and how evidence was captured.

Cloud governance & policy enforcement

Azure Policy initiative, subscription-level assignment, region controls and mandatory tagging.

Governance Azure Policy Implemented

Azure Policy Initiative assigned

A custom governance baseline was applied to enforce approved regions, mandatory tags and storage security controls.

RiskUncontrolled cloud deployments and inconsistent governance controls
DecisionApply a subscription-level Azure Policy initiative as the governance baseline
Non-compliance Policy enforcement Detected

Non-compliant policies identified

Azure Policy identified non-compliance including missing tags and resources outside approved regions.

ThreatGovernance drift and unmanaged cloud assets
ControlPolicy-based detection and enforcement of required standards
Finding Non-compliant resource Validated

Non-compliant resource evidence

Individual resource-level evidence was captured to show exactly which resources breached governance controls.

RiskPolicy summaries without traceable evidence are weak for audit purposes
DecisionCapture resource-level compliance details for audit traceability

Risk detection with Azure Resource Graph

Resource Graph queries used to detect missing tags, non-approved regions and storage security posture.

Governance Missing ownership Detected

Resources missing Owner tag

Missing ownership metadata was detected to highlight accountability and governance gaps.

RiskNo clear ownership for remediation, cost, or incident response
DecisionUse Resource Graph to identify missing tags across resources
Risk Region governance Detected

Resources outside approved regions

Resources outside approved UK regions were identified to demonstrate data residency and regional governance monitoring.

RiskData residency breach or inconsistent regional control enforcement
DecisionAllow only UK South and UK West in the governance baseline
Security Storage exposure Reviewed

Storage public access status

Storage accounts were checked for public blob access to validate exposure risk and data protection posture.

ThreatAnonymous access to sensitive data stored in blob containers
DecisionQuery storage public access configuration and monitor for risky settings
Security Secure transfer Reviewed

Secure transfer validation

Storage accounts were checked for secure transfer settings to support encrypted traffic requirements.

RiskUnencrypted traffic to storage services
DecisionValidate storage secure transfer status using Resource Graph

Automation & compliance checks

Azure Functions used to simulate scheduled compliance checks and support ongoing monitoring.

Automation Serverless Implemented

Timer-triggered compliance function

A scheduled Azure Function was created to demonstrate how compliance checks can run automatically.

RiskManual compliance checks are inconsistent and not repeatable
DecisionUse a timer-triggered Function to automate governance monitoring
Monitoring Function execution Validated

Function execution monitored

Function execution and performance were reviewed to confirm the automation was running as expected.

RiskAutomation exists but cannot be validated operationally
DecisionUse availability and performance views to validate execution behaviour

Audit evidence repository

Storage containers and evidence artefacts used to support compliance reporting and audit readiness.

Evidence Audit readiness Implemented

Evidence repository created

Azure Storage was used to hold compliance snapshots, reports and risk summaries.

RiskCompliance findings cannot be evidenced during audit or review
DecisionCreate dedicated evidence storage for governance outputs and reports
Storage Container design Implemented

Evidence containers configured

Containers were created for compliance reports, evidence files and AI governance assessments.

RiskUnstructured evidence makes audit review harder
DecisionSeparate evidence by purpose using dedicated storage containers

Challenges, issues & resolution

Real-world deployment challenges caused by policy enforcement, quota limits and monitored resource dependencies.

Issue Policy enforcement Resolved

Policy blocked resource deployment

Strict tagging controls blocked Azure from creating dependent resources that did not meet governance requirements.

Root causeDeny policy required Owner tag and blocked auto-created resources
ResolutionCreated compliant supporting resources manually and aligned deployments with governance controls
Issue Function deployment Troubleshot

Function deployment issue investigated

Function App deployment was impacted by policy dependencies and regional quota constraints during implementation.

ChallengeDeployment failed while creating monitoring and function resources
ResolutionAdjusted region selection and deployed supporting monitoring resources in a compliant way
