Project 1: AWS Cloud Security Fundamentals

Cloud security · Identity & access control · Network segmentation · Logging & auditability

Objective

Goal

Design and deploy a secure AWS environment demonstrating how cloud security principles reduce risk and support governance and compliance requirements.

Implemented

What I Built

  • Secure AWS account with foundational security controls.
  • IAM roles and policies aligned to least-privilege principles.
  • VPC design with public and private subnet separation.
  • Network access controls using security groups.
  • Centralised logging and monitoring via CloudTrail.
Outcomes

Approach & Results

  • Structured delivery: scope, risk identification, control implementation.
  • Documented security decisions and residual risks throughout.
  • Produced artefacts suitable for stakeholder walkthroughs.

Project 2: SIEM Visibility & Incident Detection

Security monitoring · Detection engineering · Incident response workflows · Splunk

Objective

Goal

Establish security visibility through log collection and demonstrate how raw events become actionable alerts within a SIEM platform.

Implemented

What I Built

  • Connected systems to Splunk for structured log ingestion.
  • SPL detection rules for brute force, encoded PowerShell and privilege changes.
  • Dashboards to surface trends, anomalies and notable events.
  • Alert triage, investigation workflows and automation.
Outcomes

Approach & Results

  • Mapped detections to MITRE ATT&CK techniques.
  • Demonstrated the link between technical alerts and business risk.
  • Documented findings and detection coverage recommendations.

Project 3: Cyber GRC & Azure Cloud Governance Platform

ISO 27001 · Azure Policy · Risk management · Compliance monitoring · Audit evidence

Objective

Goal

Design a lightweight ISMS and operationalise governance through Azure Policy enforcement, compliance monitoring and audit-ready evidence collection.

Implemented

What I Built

  • ISMS-style risk register, asset identification and data classification.
  • Azure Policy initiative enforcing tagging, regions and storage security.
  • Resource Graph queries to detect misconfigurations and drift.
  • Timer-triggered Azure Function for automated compliance checks.
  • Core security policies, control mappings and GRC artefacts.
Outcomes

Approach & Results

  • Full traceability between risks, controls and governance objectives.
  • Governance foundation aligned to ISO 27001 and NIST CSF 2.0.
  • Practical experience troubleshooting policy and deployment issues.
