Project 1: AWS Cloud Security Fundamentals

Cloud security · Identity & access control · Network segmentation · Auditability

Objective

To design and deploy a secure AWS environment, demonstrating how cloud security principles can be applied to reduce risk and support governance and compliance requirements.

What I Implemented

  • Secure AWS account setup with foundational security controls.
  • IAM users, roles and policies aligned to least-privilege principles.
  • VPC design with public and private subnet separation.
  • Network access controls using security groups and flow logging.
  • Centralised logging and monitoring to support investigation and audit.

Approach & Outcomes

  • Applied a structured delivery approach: scope, risk identification, control implementation.
  • Documented security decisions and residual risks throughout the build.
  • Produced artefacts suitable for stakeholder walkthroughs and interview discussion.

Project 2: SIEM Visibility & Incident Detection

Security monitoring · Detection engineering · Incident response workflows

Objective

To establish security visibility through log collection and demonstrate how raw events become actionable alerts within a SIEM platform.

What I Implemented

  • Connected systems to a SIEM for structured log ingestion.
  • Created detection rules for suspicious authentication activity and privilege changes.
  • Built dashboards to surface trends, anomalies and notable events.
  • Performed basic alert triage, investigation and documentation.

Approach & Outcomes

  • Mapped detections to common attack behaviours and MITRE ATT&CK techniques.
  • Demonstrated the link between technical alerts and business risk context.
  • Documented findings, limitations and recommended improvements to detection coverage.

Project 3: Cyber GRC & Azure Cloud Governance Platform

ISO 27001 · Azure Policy · Risk management · Compliance monitoring · Audit evidence

Objective

To design a lightweight Information Security Management System (ISMS) and operationalise governance through Azure Policy enforcement, compliance monitoring and audit-ready evidence collection.

What I Implemented

  • ISMS-style risk register, asset identification and data classification.
  • Azure Policy initiative enforcing tagging, region controls and storage security.
  • Resource Graph queries to detect misconfigurations and governance drift.
  • Automated compliance checks using a timer-triggered Azure Function.
  • Core security policies, control mappings and GRC artefacts.

Approach & Outcomes

  • Ensured traceability between risks, controls and governance objectives.
  • Applied project discipline to structure documentation, reviews and evidence collection.
  • Created a practical governance foundation aligned to ISO 27001 and NIST CSF 2.0.
