Cyber GRC & Azure Cloud Governance Platform

A practical GRC case study demonstrating how ISO 27001-style governance, risk management and cloud security controls can be applied within Microsoft Azure.

← Back to Projects View project evidence →

1. Executive Summary

This project demonstrates the design and implementation of a lightweight governance, risk and compliance model for a simulated organisation, Helios Energy Analytics. The aim was to show how GRC principles can move beyond documentation and be applied directly within a cloud environment.

The solution combines ISMS-style thinking, Azure Policy, Resource Graph queries, compliance monitoring and evidence collection to demonstrate a practical governance operating model.

2. Project Objectives

  • Design a practical GRC model aligned to ISO 27001 principles.
  • Apply cloud governance controls using Azure Policy.
  • Detect and classify common cloud risks and misconfigurations.
  • Create audit-ready evidence to support compliance reporting.
  • Demonstrate how governance can be automated and monitored over time.

3. Governance & ISMS Approach

I designed a lightweight ISMS-style approach focused on accountability, traceability and proportionate control selection. The governance model linked assets, risks, owners, policies and controls together so that security decisions could be explained clearly to both technical and non-technical stakeholders.

  • Defined ownership and accountability for cloud resources.
  • Mapped risks to practical mitigating controls.
  • Established policy requirements for tagging, location and storage security.
  • Created a structure for ongoing review, exception handling and evidence capture.

4. Azure Governance Implementation

To translate the GRC model into a real technical environment, I implemented an Azure Policy initiative called Helios Governance Baseline. This baseline applied governance controls at subscription level and helped enforce consistent standards across the environment.

  • Mandatory ownership tagging to improve accountability.
  • Approved Azure regions to support location and data residency control.
  • Storage account security policies to reduce exposure risk.
  • Policy effects including deny and audit to enforce or monitor compliance.

5. Risk Identification & Monitoring

I used Azure Policy and Azure Resource Graph to identify governance gaps and security risks across the environment. The project was designed to show both compliant and non-compliant outcomes, making it clear how cloud risks can be surfaced and reviewed.

  • High risk: public storage exposure.
  • High risk: unrestricted network security group access.
  • Medium risk: resources deployed outside approved regions.
  • Medium risk: missing ownership tags.

6. Automation & Evidence Collection

A timer-triggered Azure Function was introduced to demonstrate how compliance checks could be automated and repeated over time. I also created an evidence repository in Azure Storage to hold compliance snapshots, risk summaries and audit artefacts.

This helped demonstrate how governance can become operational rather than remaining a static policy document.

7. Challenges & Resolution

The project included realistic implementation challenges that reflected how governance controls can affect day-to-day cloud delivery.

  • Policy blocked deployments: resolved by aligning resources with required tags and governance standards.
  • Auto-created resources failed policy checks: resolved by manually creating compliant supporting resources.
  • Regional quota limitations: resolved by selecting an alternative Azure region for deployment.
  • Query issues: resolved by adjusting Resource Graph queries and validating results against the Azure portal.

8. Outcome

The final outcome was a working Azure governance case study showing the full lifecycle of GRC in practice: policy definition, enforcement, detection, remediation, automation and evidence collection.

The project demonstrates practical capability across cloud governance, Azure security, risk management, compliance monitoring and audit readiness.
