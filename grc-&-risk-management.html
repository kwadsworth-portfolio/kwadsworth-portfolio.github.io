Project 3: Cyber GRC & Azure Cloud Governance Platform

Governance, risk and compliance initiative aligned to ISO 27001 principles, demonstrating how a lightweight ISMS and structured risk management can support better security decision-making.

← Back to Projects

1. Overview

This project focused on designing a lightweight ISMS and risk management approach. The aim was to demonstrate how governance, risk and control can be applied in a practical, scalable way.

2. Scope & Objectives

  • Establish a GRC framework aligned to ISO 27001.
  • Create a structured risk register.
  • Define proportionate controls mapped to risks.
  • Produce governance documentation and accountability model.

3. ISMS & Risk Design

A mini-ISMS was designed with focus on traceability between assets, risks and controls.

  • Asset identification and classification
  • Risk scoring model
  • Threat and vulnerability mapping
  • ISO-style control alignment

4. Governance, Policies & Procedures

  • Defined ownership and accountability
  • Created core security policies
  • Established review cycles
  • Defined exception handling process

5. Outcomes & Lessons Learned

  • Clear linkage between risks and controls
  • Improved stakeholder visibility
  • Scalable governance model

6. Applied Case Study: Azure Cloud Governance (Helios Platform)

End-to-end Azure governance implementation demonstrating real-world GRC application.

To complement the ISMS design, I implemented a cloud governance solution in Azure, demonstrating how policy enforcement, monitoring and evidence collection operate in practice.

Governance Implementation

  • Created Azure Policy Initiative ("Helios Governance Baseline")
  • Enforced tagging, region and storage controls
  • Applied governance at subscription level

Risk Identification

  • High: Public storage access
  • High: Open network security group
  • Medium: Non-approved region
  • Medium: Missing tags

Detection & Monitoring

Azure Resource Graph was used to query and validate compliance across resources.

Automation

A timer-triggered Azure Function was implemented to simulate automated compliance monitoring.

Evidence & Audit

Compliance outputs were stored in Azure Storage to simulate an audit-ready evidence repository.

Challenges

  • Policy blocking resource deployments
  • Tag enforcement preventing auto-created resources
  • Regional quota limitations

Resolution

  • Aligned deployments with governance controls
  • Manually created compliant resources
  • Adjusted queries for accurate results
  • Used alternative regions

Outcome

Demonstrates full GRC lifecycle: policy definition, enforcement, detection, remediation and evidence collection.

Aligns with ISO 27001 (Access Control, Network Security) and NIST CSF (Identify, Protect, Detect).
