3. Environment Setup

Splunk was installed in a lab environment and a Windows endpoint was configured to generate security telemetry. Sysmon was enabled to capture process creation and command-line activity.

  • Splunk installed and accessible via the web interface.
  • Windows endpoint configured and sending events.
  • Sysmon running and producing structured process and network events.
  • Time synchronisation verified across systems.

4. Log Onboarding & Validation

Confirmed that key Windows Security and Sysmon EventCodes were indexing correctly using the following SPL queries: 

index=wineventlog sourcetype="WinEventLog:Security"
| stats count by EventCode
| sort -count
index=sysmon
| stats count by EventCode
| sort -count

5. Detections (SPL + Evidence)

5.1 Brute Force Login Attempts

index=wineventlog sourcetype="WinEventLog:Security" EventCode=4625
| stats count as fails values(Account_Name) as users by IpAddress, host
| where fails >= 10
| sort -fails

5.2 Suspicious PowerShell (Encoded Commands)

index=sysmon EventCode=1 Image="*\\powershell.exe"
(CommandLine="*-enc*" OR CommandLine="*-EncodedCommand*")
| table _time host User Image CommandLine
| sort -_time

5.3 New Local User / Admin Group Change

index=wineventlog sourcetype="WinEventLog:Security" (EventCode=4720 OR EventCode=4732)
| table _time host SubjectUserName TargetUserName GroupName
| sort -_time
