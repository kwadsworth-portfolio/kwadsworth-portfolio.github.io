4. Log Onboarding & Validation

Confirmed that key Windows Security and Sysmon EventCodes were indexing correctly. 

index=wineventlog sourcetype="WinEventLog:Security"
| stats count by EventCode
| sort -count
index=sysmon
| stats count by EventCode
| sort -count

5. Detections (SPL + Evidence)

5.1 Brute force login attempts

index=wineventlog sourcetype="WinEventLog:Security" EventCode=4625
| stats count as fails values(Account_Name) as users by IpAddress, host
| where fails >= 10
| sort -fails

5.2 Suspicious PowerShell (encoded)

index=sysmon EventCode=1 Image="*\\powershell.exe"
(CommandLine="*-enc*" OR CommandLine="*-EncodedCommand*")
| table _time host User Image CommandLine
| sort -_time

5.3 New local user / admin group change

index=wineventlog sourcetype="WinEventLog:Security" (EventCode=4720 OR EventCode=4732)
| table _time host SubjectUserName TargetUserName GroupName
| sort -_time
