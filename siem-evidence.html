Detections (SPL queries + evidence)

Detection rules for authentication abuse, suspicious execution and privilege changes.

Risk Brute force / credential abuse Detected

Brute force login attempts

Detects multiple failed logins from the same source — a common indicator of credential stuffing or brute force activity.

ThreatAttacker attempting to guess credentials via repeated authentication failures
DecisionAlert when a single source generates 10+ failed logins against any host
index=wineventlog sourcetype="WinEventLog:Security" EventCode=4625 | stats count as fails values(Account_Name) as users by IpAddress, host | where fails >= 10 | sort -fails
Risk Suspicious execution Detected

Suspicious PowerShell (encoded commands)

Detects PowerShell launched with encoded command arguments — a common technique used to obfuscate malicious activity.

ThreatAttacker using encoded PowerShell to bypass script-based defences or logging
DecisionFlag any PowerShell execution using -enc or -EncodedCommand for review
index=sysmon EventCode=1 Image="*\\powershell.exe" (CommandLine="*-enc*" OR CommandLine="*-EncodedCommand*") | table _time host User Image CommandLine | sort -_time
Risk Privilege escalation Detected

New local user / admin group change

Detects new local account creation or addition to privileged groups — often indicative of persistence or privilege escalation.

ThreatAttacker creating a backdoor account or escalating privileges on a compromised host
DecisionAlert on EventCode 4720 (user created) and 4732 (added to admin group)
index=wineventlog sourcetype="WinEventLog:Security" (EventCode=4720 OR EventCode=4732) | table _time host SubjectUserName TargetUserName GroupName | sort -_time
